# 中国党政会议文件聚合平台

## 📋 简介

自动聚合中国党政重要会议的官方文件、公报、通稿，按会议分类展示，来源包括新华社、中国政府网、国新网等权威渠道。

## 📊 覆盖的会议

| 会议 | 频次 | 更新周期 |
|------|------|---------|
| 党代会 | 每5年 | 逢2/7年10月-11月每2天 |
| 中央全会 | 每年至少1次 | 每月1日、15日 |
| 中央经济工作会议 | 每年12月 | 12月5日-25日每2天 |
| 全国两会 | 每年3月 | 3月1日-15日每天 |
| 中央政治局会议 | 每月1次 | 每月20日-月底每3天 |
| 中央财经委会议 | 不定期 | 每月1日 |
| 中央深改委会议 | 不定期 | 每月1日 |
| 中央金融工作会议 | 约5年1次 | 逢3/8年10月-11月每2天 |
| 国务院常务会议 | 每月2-3次 | 每周一 |
| 国新办发布会 | 高频 | 每周一 |

## 🔗 数据来源

- 新华社 (xinhuanet.com) — 党代会、中央全会、中央经济工作会议、政治局会议、财经委、深改委、金融工作会议
- 中国政府网 (gov.cn) — 全国两会、国务院常务会议
- 国新网 (scio.gov.cn) — 国新办新闻发布会
